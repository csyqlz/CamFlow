## 📖 简介

CamFlow 是一款面向 WordPress 系统的内容互动自动化工具，专为增强网站活跃度和用户互动而设计。通过智能化的用户池管理、自动评论生成和社区帖子发布，帮助站长轻松提升站点内容丰富度。

## ✨ 核心功能

### 🎯 用户池管理
- **智能用户生成** - 自动创建真实感的用户账号
- **AI 昵称生成** - 支持 OpenAI 兼容接口、Google Gemini、OpenRouter
- **备用词库** - AI 失败时使用本地抽象词库
- **随机头像** - 集成 DiceBear API 生成多样化头像
- **批量管理** - 支持批量删除和补齐用户池

### 💬 评论互动
- **自动评论** - 定时或手动生成文章评论
- **多种风格** - 支持提问型、赞同型、补充型、讨论型
- **智能目标** - 可选择普通文章或子比主题社区帖子
- **审核控制** - 可设置待审核或直接发布
- **AI 生成** - 结合标题和摘要生成自然评论

### 📮 社区发帖
- **自动发帖** - 支持子比主题 forum_post 类型
- **板块分配** - 自动选择随机板块（plate）
- **话题标签** - 自动绑定话题（forum_topic）和标签（forum_tag）
- **AI 内容** - 根据标题生成自然的帖子正文
- **备用模板** - AI 失败时使用本地模板

### 🤖 AI 接入
- **OpenAI 兼容接口** - 支持 New API、sub2api、One API 等中转服务
- **Google Gemini API** - 支持 Gemini 2.5 Flash Lite 等模型
- **OpenRouter** - 支持免费模型（:free 后缀）
- **模型列表获取** - 一键读取可用模型
- **连接测试** - 实时测试 API 可用性
- **备用机制** - AI 失败自动切换本地模板

### 📊 运行日志
- **详细记录** - 记录所有用户、评论、帖子生成活动
- **状态分类** - 成功、失败、提醒、信息
- **错误追踪** - AI 错误、数据库错误详细记录
- **日志管理** - 支持清空和自动限制条数（最多 120 条）

### 🔄 自动更新
- **GitHub 集成** - 自动检查 GitHub Release 最新版本
- **一键更新** - 后台直接下载并更新插件
- **版本提示** - 实时显示当前版本和最新版本
- **更新日志** - 显示 Release 的更新说明

### ⏰ 定时任务
- **每日自动运行** - 可设置固定时间（如凌晨 02:30）
- **安全确认** - 需要站点确认才能执行自动化
- **立即执行** - 支持手动触发一次任务
- **下次运行提示** - 显示下一次计划执行时间

## 🚀 快速开始

### 环境要求
- WordPress 5.8 或更高版本
- PHP 7.4 或更高版本（推荐 PHP 8.1+）
- MySQL 5.7 或更高版本

### 安装步骤

1. **下载插件**
   ```bash
   # 从 GitHub Release 下载最新版本
   https://github.com/csyqlz/CamFlow/releases/latest
   ```

2. **上传安装**
   - 在 WordPress 后台 → 插件 → 安装插件 → 上传插件
   - 选择 `CamFlow.zip` 文件上传
   - 点击"现在安装"

3. **启用插件**
   - 安装完成后点击"启用插件"
   - 进入"用户自动化"菜单进行配置

### 基础配置

#### 1. 计划任务设置
```
总览 → 计划任务
✓ 勾选"我确认当前站点允许执行自动化内容互动"
✓ 勾选"启用每日定时任务"
✓ 设置每日运行时间（例如：02:30）
```

#### 2. 用户池配置
```
用户池 页面
- 用户池数量：200（默认）
- 登录名前缀：flow_（推荐）
- 点击"补齐 200 用户池"
```

#### 3. AI 接入（可选但推荐）
```
AI 接入 页面
- 启用 AI：✓
- AI 服务：选择你的服务商
  - OpenAI 兼容：填写 API Base 和 Key
  - Google Gemini：填写 API Key
  - OpenRouter：填写 API Key
- 点击"测试连接"确认可用
```

#### 4. 评论设置
```
评论互动 页面
- 每日评论数量：10（建议）
- 评论发布状态：待审核（首次建议）
- 抽取范围：80（最近 80 篇内容）
- 目标内容：普通文章 ✓ / 社区帖子 ✓
- 评论风格：混合随机
```

#### 5. 社区发帖（需要子比主题）
```
社区发帖 页面
- 自动生成社区帖：✓
- 每日社区帖数量：2（建议）
```

## 📚 使用场景

### 场景 1：新站点冷启动
**问题**：新网站没有用户，评论区空荡荡，显得不活跃

**解决方案**：
1. 配置用户池 200 个
2. 设置每日评论 20 条（待审核）
3. 运行 3-5 天后，站点看起来有真实用户互动
4. 逐步减少自动评论数量，引入真实用户

### 场景 2：社区论坛活跃度提升
**问题**：子比主题社区板块发帖少，显得冷清

**解决方案**：
1. 启用社区发帖功能
2. 每日生成 2-5 个社区帖
3. 配置 AI 生成真实内容
4. 社区帖同时生成评论互动

### 场景 3：无 AI 预算的站点
**问题**：没有 AI API 预算，但想要自然的评论

**解决方案**：
1. 关闭 AI 或设置为"不使用 AI"
2. 编写丰富的备用评论模板（多写几条）
3. 选择"混合随机"评论风格
4. 定期更新备用模板避免重复

## 🔧 故障排查

### 问题 1：点击"补齐用户"报错
**症状**：Deprecated warning 或 Parse error

**解决方案**：
- 确认使用 v1.2.7 或更高版本
- 检查 PHP 版本是否 7.4+
- 查看 WordPress 调试日志

### 问题 2：AI 生成失败
**症状**：运行日志显示"AI 调用失败"

**排查步骤**：
1. 点击"测试连接"确认 API 可用
2. 检查 API Key 是否正确
3. 检查 API Base URL 格式
4. 查看运行日志中的错误详情
5. 确认 AI 服务商有余额/配额

### 问题 3：评论未生成
**症状**：每日任务运行但没有新评论

**排查步骤**：
1. 检查"站点确认"和"每日自动运行"是否勾选
2. 查看运行日志的失败原因
3. 确认有可评论的内容（发布状态、评论开启）
4. 检查用户池是否有可用用户

### 问题 4：社区帖无法生成
**症状**：运行日志显示"无法发布社区帖"

**原因**：
- 当前主题未注册 `forum_post` 类型
- 仅子比主题支持社区功能

## 📊 性能建议

### 数据量建议
```
用户池：100-300 个（推荐 200）
每日评论：5-20 条（新站可多一些）
每日帖子：1-5 篇（避免过度）
抽取范围：50-100 篇内容
```

### 服务器资源
```
每日任务耗时：约 30-120 秒
内存占用：约 20-50 MB
数据库查询：每条评论约 5-10 次
```

## 🔒 安全说明

### 数据隐私
- 所有生成的用户使用 `@example.invalid` 邮箱（无法收信）
- 用户密码随机生成 24 位强密码
- 所有生成内容标记元数据，可随时批量删除

### 权限控制
- 仅"manage_options"权限用户可访问设置
- 所有 AJAX 请求验证 nonce
- 文件操作前检查用户权限

### 数据清理
```
卸载插件时自动清理：
✓ 所有生成的用户
✓ 所有生成的评论
✓ 所有生成的社区帖
✓ 插件配置选项
✓ 运行日志
```
