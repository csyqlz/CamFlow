# CamFlow

面向 WP 系统的内容互动自动化插件。后台菜单显示为“用户自动化”，插件页面标题为“CamFlow”。

## 主要功能

- 设置页拆分为多个标签页，减少后台页面过长的问题。
- 默认维护 200 个用户池账号，生成用户、生成评论、社区帖分别管理。
- 每日定时任务支持设置具体运行时间，也支持手动重新安排和立即执行。
- 评论和社区帖支持 New API、sub2api、One API 等 OpenAI 兼容接口，也保留 Gemini API 与 OpenRouter 免费模型，不调用本地 AI 模型。
- AI 接入页支持点击获取模型列表，也支持测试连接，模型可点击回填。
- 评论失败、社区帖失败、用户创建异常会写入运行日志；AI 生成成功时会记录使用的服务和模型。
- 单独提供用户管理、评论管理、帖子管理和运行日志页面。
- 用户昵称优先通过已配置的云端 AI 批量生成，失败时使用本地抽象词库兜底。
- 从 WordPress 后台删除插件时，会清理插件设置、运行日志和插件生成的数据。

## 免费 AI 接入

后台进入“用户自动化 > AI 接入”：

1. 推荐选择 `OpenAI 兼容接口（New API / sub2api / One API）`，填写接口地址、API Key 和模型名。接口地址可填写 `https://你的域名/v1`，也可以填写完整的 `/v1/chat/completions` 地址。
2. 模型名以服务商后台可用模型为准，可选择建议项，也可以手动输入，例如 `gpt-4o-mini`、`deepseek-chat`、`qwen-plus`、`glm-4-flash`。
3. 填好接口后可点击“获取模型列表”，读取 `/v1/models` 返回的大模型；点击模型名会自动填入当前模型框。
4. 点击“测试连接”会发起一次最小对话请求，成功会显示当前模型，失败会显示 HTTP 状态或接口错误原因。
5. 也可以选择 `OpenRouter 免费模型` 或 `Google Gemini API`，填写对应 API Key 和模型 ID。
6. 免费额度和可用模型可能会被服务商调整；接口失败时插件会自动使用备用模板。

## 公开更新发布规则

插件更新源固定为 GitHub 公开仓库 `csyqlz/CamFlow`，用户后台不提供仓库、Token 或更新包地址填写项。

发布新版本时：

1. 修改 `CamFlow.php` 中的插件版本号和 `ZIBI_NAME_VERSION`。
2. 将插件目录打包为 `CamFlow.zip`，压缩包顶层必须是 `CamFlow/`，入口文件必须是 `CamFlow/CamFlow.php`。
3. 在 GitHub 创建 Release，标签使用 `v版本号` 格式，例如 `v1.2.6`。
4. 上传附件 `CamFlow.zip`。插件后台只会识别这个固定附件名。

## 使用建议

- 先在“计划任务”里设置每日运行时间，再按需开启每日自动运行。
- 评论默认建议保持“待审核”，确认内容风格后再切换为直接发布。
- 评论或发帖数量异常时，优先查看“运行日志”的失败原因和关联信息。
- 后续可继续加入内容去重、关键词屏蔽、AI 接口健康检查、管理列表分页筛选等能力。
